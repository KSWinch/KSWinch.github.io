Official Kings Website

This is my biggest project to date. I created a website for our Kings hockey team. The website is a full stack application that allows users to view the team's schedule, roster, and stats. Official Kings Hockey also contains Vitests to ensure the website can avoid as little downtime as possible. The website is built using React, CSS, JavaScript, AWS, and MySQL.

DK Tracker

DK Tracker is a workout tracking application designed to help users log exercises, track progress, and stay consistent with their fitness goals. The app lets users record workouts, track sets and reps, and review performance over time to build better routines. It is built using a modern web stack with a focus on usability, clean data tracking, and a simple experience for everyday training.

Key tools and technologies used: React, JavaScript, CSS, Node.js, Express, PostgreSQL, Docker, and Jenkins.

League of Legends Summoner Search

This project is a simple web application that allows users to search for a League of Legends Summoner.

This project allows users to search for a League of Legends summoner and display their statistics. The application fetches data from the Riot Games API and displays information such as the summoner's rank, recent match history, and champion statistics. The project is built using React, CSS, JavaScript, and the Riot Games API.

About

Last updated: October 2026

I’m a software developer with a strong focus on full-stack web development and building practical applications that solve real problems. I graduated from Algonquin College’s Computer Science program and I’m currently continuing to grow my skills through hands-on projects, personal development work, and modern web technologies.
